# Part B - Logic Synthesis with Yosys

## Commands (inside IIC-OSIC-TOOLS, from the repository root)

```bash
# Synthesis (Yosys 0.70, SKY130 sky130_fd_sc_hd, tt_025C_1v80 Liberty)
yosys -c synth/synth.tcl

# Gate-level simulation of the synthesized netlist with the Part A testbench
CELLS=$PDK_ROOT/sky130A/libs.ref/sky130_fd_sc_hd/verilog
iverilog -g2012 -DFUNCTIONAL -DUNIT_DELAY=#1 -o gls \
  tb/tb_mult.v $CELLS/primitives.v $CELLS/sky130_fd_sc_hd.v synth/mult_array_netlist.v
vvp gls
```

`synth/synth.tcl` runs the 7 required steps: `read_verilog`, `synth -top mult_array -flatten`,
`dfflibmap -liberty $lib`, `abc -liberty $lib`, `opt_clean -purge`,
`tee -o synth/mult_array_stat.rpt stat -liberty $lib`, `write_verilog -noattr synth/mult_array_netlist.v`.

## Notes for the report

- Logic cells = 73 - 16 flip-flops = **57** combinational cells (30 different cell types), not 16 AND + 12 FA = 28.
  ABC maps the flattened logic to whatever SKY130 gates minimise area/delay: AND gates are merged into
  compound cells (`a21oi`, `o2111a`, `nand4`, ...) and each full adder is split into XOR/XNOR + majority-style
  gates. ABC cannot use the multi-output SKY130 full-adder cell `fa_1` (log: "Detected 9 multi-output cells"),
  so no single-cell full adders appear.
- Flip-flops are only 16 of 73 cells (22 %) but 49.69 % of the area, because one `dfrtp_1`
  (25.024 um^2) is larger than any logic gate in the design: 6.7x a `nand2_1` (3.754 um^2) and still
  larger than the biggest gate, `xor3_1` (23.773 um^2). The average logic cell is 405.4 / 57 = 7.1 um^2.
- Re-running `yosys -c synth/synth.tcl` reproduces the committed netlist and report byte-for-byte.
